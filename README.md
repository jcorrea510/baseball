# Sandlot

A browser baseball batting game. You are at the plate: watch the pitcher, time your
swing, and try to crush the ball over the fence. Everything (art, sounds, players,
team names) is original and generated by code - nothing is downloaded.

*(Full description, controls and tuning guide are added as the game comes together.)*

## Run it on your computer

```bash
npm install
npm run dev      # then open the address it prints (usually http://localhost:5173)
```

Other commands: `npm test` (automated checks), `npm run build` (make the final site in `dist/`).

## Publishing

Every push to the `main` branch is built and published to GitHub Pages by
`.github/workflows/deploy.yml`. One-time setup on GitHub: **Settings -> Pages ->
Build and deployment -> Source: GitHub Actions**.
